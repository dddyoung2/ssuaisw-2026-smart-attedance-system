# AI 얼굴 탐지 및 인식 모델 실험(/src/exp/)

> 출결 시스템에 사용되는 AI 얼굴 탐지 및 인식 모델을 결정하고, 개선하기 위해 진행된 실험 코드   

| 분류 | 디렉터리 | 내용 |
|---|---|---|
| 얼굴 탐지 모델 | `face-detection/` | 얼굴 탐지 모델 관련 실험 |
| 얼굴 인식 모델 | `face-recognition/` | 얼굴 인식 모델 관련 실험 |

## 규칙
- 데이터셋을 올리지 않는다.
    - 학생 얼굴 사진, 얼굴 크롭, 특징 벡터를 올리지 않는다.
- 모델 가중치를 올리지 않는다.
